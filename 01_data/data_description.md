## Data

This folder contains information regarding the raw input sequencing data used for the Vertebrate Genome Assembly pipeline, completed as part of the Galaxy Training Network (GTN) hands-on tutorial.
All three data types were required to produce a chromosome-level, haplotype-resolved genome assembly:

### HiFi Reads:
PacBio HiFi long reads used for initial contig assembly with HiFiasm
### Hi-C Reads:
Illumina paired-end chromatin contact reads used for haplotype phasing and chromosome-level scaffolding with YaHS
### Bionano Optical Map:
Enzyme-labelled optical mapping data used for large-scale structural scaffolding with Bionano Solve

Raw data files are not uploaded due to size limitations. All datasets are publicly available and were imported from Zenodo via the GTN Vertebrate Genome Assembly tutorial.
